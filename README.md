# Number Guessing Game

A simple Python Number Guessing Game project.

## Features
- Easy, Medium and Hard levels
- Random number generation
- Higher/Lower hints
- Attempt counter
- Best score tracking
- Replay option

## Technologies Used
- Python
- Random Module

## How to Run

```bash
python number_guessing_game.py
```
